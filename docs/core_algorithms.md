# 核心算法

## 1. 三频四步相移

对每个频率 `f ∈ {1, 4, 12}`，投射四幅相位相差 90° 的正弦条纹。设采集灰度为 `I0`、`I90`、`I180`、`I270`，包裹相位为：

```text
C = I0 - I180
S = I270 - I90
phi_f = atan2(S, C)
```

平均亮度、调制度和归一化调制度分别为：

```text
A = (I0 + I90 + I180 + I270) / 4
M = 0.5 * sqrt(C² + S²)
R = M / (A + epsilon)
```

`R` 同时反映条纹对比度和局部照明强度，是阴影、曝光不足和低反射区域的重要置信度指标。

## 2. 逐级多频展开

先把包裹相位映射到 `[0, 2π)`，再用低频确定高频阶次：

```text
Phi1  = phi1
k4    = round((4 * Phi1 - phi4) / 2π)
Phi4  = phi4 + 2π * k4
k12   = round((3 * Phi4 - phi12) / 2π)
Phi12 = phi12 + 2π * k12
u_p   = projector_width * Phi12 / (24π)
```

同时计算 `Phi4 - 4*Phi1` 和 `Phi12 - 3*Phi4` 的包裹残差。残差过大的像素被剔除，不进入三角测量。

## 3. 相机—投影仪三角测量

相机像素 `(u_c, v_c)` 通过内参 `K_c` 反投影为相机射线，再由相机外参变换到世界坐标：

```text
r_c ∝ R_c K_c^-1 [u_c, v_c, 1]^T
X(t) = C_c + t r_c
```

解码得到的是投影仪横坐标 `u_p`。固定 `u_p` 的投影仪像素构成一束共面光线。用该列顶部和底部两条投影射线的叉乘得到投影列平面法向 `n_p`。相机射线与平面的交点参数为：

```text
t = n_p · (C_p - C_c) / (n_p · r_c)
X = C_c + t r_c
```

代码位于 `reconstruction/triangulate.py`。BlenderProc 输出的深度只用于生成误差真值，不参与 `X` 的计算。

## 4. 像素级置信度筛选

有效掩膜由以下条件的交集构成：

```text
valid = depth_range
      ∩ average_intensity
      ∩ modulation_ratio
      ∩ not_saturated
      ∩ unwrap_residual
      ∩ projector_bounds
      ∩ local_phase_consistency
      ∩ triangulation_range
      ∩ object_ROI
```

无效位置只在计算邻域中值时使用最近有效值临时填充，最终输出不会把该填充值当成真实测量点。

## 5. 转台坐标统一

视角 `theta` 下得到的是旋转后物体的世界坐标点。系统执行绕 Z 轴的 `-theta` 旋转，将其恢复到物体 0° 坐标系：

```text
X_canonical = Rz(-theta) X_world
```

仿真使用已知转台角度，实物系统应使用编码器角度和标定后的真实转轴矩阵。

## 6. ROI 约束 TSDF 体积链路

每个视角的稀疏结构光点重新投影为深度图。只对小缺口做受限形态学闭运算和最近邻深度填充，并保留超过面积阈值的连通区域。随后使用 Open3D Scalable TSDF：

- 体素尺寸：1 mm；
- 截断距离：4 mm；
- 深度单位：米；
- 深度采样步长：1；
- 物体 ROI：径向和 Z 范围双重约束。

体积由 TSDF 主连通分量的有向三角面体积得到。仿真观察到主要偏差近似与表面积成正比，因此使用标准立方体估计等效表面偏移 `delta = 0.702765548 mm`：

```text
V_corrected = V_raw + delta * A_mesh
```

该系数只用于当前仿真配置；真实系统必须重新标定，不能直接沿用。

## 7. 上下互补到四相机多支路融合

同侧双相机增加了水平视角，却仍共享投影阴影区域。首先使用两套不同高度的相机—投影仪基线验证互补几何：

- 上路相机 `[0.00, -0.65, 0.30]`，投影仪 `[0.20, -0.45, 0.32]`；
- 下路相机 `[0.28, -0.38, 0.025]`，投影仪 `[0.20, -0.45, 0.015]`；
- 两路均看向接近物体中心的位置。

上下路分别解码和三角测量，再通过各自标定矩阵和转台逆旋转进入同一物体坐标系。四相机扩展进一步将每个高度拆为左右两台相机，形成上左、上右、下左、下右四个独立 `rig`。`tsdf_fusion_multi_camera.py` 和 `poisson_from_multi_points.py` 接受可重复的 `--rig` 参数，因此算法并不把相机数量写死为二。额外相机用于左右冗余，不改变相移解码和三角测量原理。

## 8. 定向点云 Poisson 拓扑链路

对双路 24 个或四相机 48 个“相机 × 转台视角”点云：

1. 统一到物体坐标系并执行物理 ROI 裁剪；
2. 估计局部法向；
3. 根据每个点对应的相机位置统一法向朝向；
4. 1 mm 体素降采样；
5. Screened Poisson 重建；
6. 在 `x=0`、`z≈0.05 m` 中截面寻找闭合曲线。

双路分支恢复了约 40.69 × 40.54 mm 的内孔闭环，四相机分支恢复了约 40.33 × 40.51 mm 的闭环，并在双方孔件上恢复 2/2 个目标孔。由于 Poisson 会在未观测区域外推，体积可能明显失真，因此明确禁止把它作为正式体积输出；深竖孔中出现的填孔失败也必须进入拓扑质量控制。

## 9. 为什么采用双分支

| 算法 | 定量体积 | 通孔连续性 | 未观测区域行为 | 最终用途 |
| --- | --- | --- | --- | --- |
| ROI-TSDF | 稳定 | 内壁稀疏时可能开边界 | 局部截断融合 | 正式体积 |
| 定向点云 Poisson | 本例明显高估 | 能形成连续孔截面 | 会平滑并外推 | 拓扑与展示 |

双分支不是重复计算，而是把两种算法的适用范围写进系统规则，防止“看起来封闭”的网格给出错误体积。
