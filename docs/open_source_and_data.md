# 开源范围、数据真实性与限制

## 开源范围

本仓库公开：

- BlenderProc 场景和相机/投影仪脚本；
- 多频相位解码、三角测量、多视角融合、TSDF、Poisson 和体积计算代码；
- 仿真标定参数；
- 端到端流水线和参数扫描脚本；
- 随机长方体逐样本指标；
- 关键实验原始文本指标；
- 脱敏后的服务器运行日志；
- 报告图表生成脚本；
- 技术路线、算法和复现文档。

## 未直接放入 Git 的数据

- 2160 幅随机长方体 HDF5；
- 通孔上下双路原始 HDF5；
- 四相机水平孔、双方孔和阶梯圆柱实验的 576 帧 HDF5；
- 单视角和融合点云 NPZ/PLY；
- TSDF/Poisson 大网格；
- Blender/BlenderProc 临时目录。

这些数据合计体积较大，且可由公开代码和参数重新生成。若需要长期归档，建议后续单独发布带 SHA-256 清单的压缩数据集并在 GitHub Release/Zenodo 中引用。

## 数据真实性声明

- `artifacts/results/` 来源于 2026-11-16 至 2026-11-17 的服务器仿真实验；
- 汇总统计由逐样本 CSV 计算，不通过手工修改平均数；
- 体积真值来源于参数化模型尺寸；
- 立方体标定得到的 `0.702765548 mm` 等效表面偏移被固定应用于同一仿真配置；
- 标定立方体的校正后误差不计入泛化性能，随机长方体、L 形和通孔用于验证；
- 报告同时给出校正前体积和校正后体积；
- 网格非闭合时如实记录 `watertight=False`；
- Poisson 恢复通孔但体积高估，因此不作为体积结论；
- 当前结果不能直接代表真实硬件测量精度。
- 四相机深竖孔实验的拓扑失败和校正误差放大被保留，未从汇总中删除。

## 对比实验的公平性

水平通孔三种方案使用相同物体真值、相移频率、相位数量、转台角度、TSDF 体素和体积偏差校正。它们主要改变观测几何：

- 单相机：上路一套；
- 常规双相机：两台同侧相机，共同上方照明；
- 本文方案：上、下两套互补相机—投影仪基线。

本文方案使用互补照明方向，因此其提升应表述为“上下互补双路/四相机阵列优于当前单相机和同侧双相机基线”，不能泛化为对所有双相机系统都更优。四相机在水平孔体积误差上与最佳上下双路基本持平，主要新增收益是左右冗余覆盖和双方孔复杂件的成功恢复。

## 主要限制

1. 目前是理想化或半理想化仿真，没有用真实相机噪声分布反标参数；
2. 体积偏差只用一个标准立方体标定，实物必须采用多个尺寸标准件；
3. TSDF 主网格仍可能非 watertight，当前体积使用主连通分量有向体积，需在实物阶段增加边界一致性门槛；
4. Poisson 会外推未观测表面，只适合拓扑辅助；
5. 曲面深孔已完成定向实验但未通过，尚未形成与随机长方体同规模的统计实验；盲孔、金属、黑色和半透明物体仍需补测；
6. 编码转台的回差、偏心、轴倾斜和温漂尚未注入；
7. 低置信度区域已经能够检测，但自动补拍/主动选视角尚未接入控制器。
8. 高深宽比竖孔即使相移有效，也可能因内壁覆盖和隐式表面闭合而被填平；这类对象必须增加专用轴向观测或明确列为测量范围外。

## 第三方软件

本仓库不复制 BlenderProc、Blender、Open3D、OpenCV、Trimesh、SciPy 等第三方源码。用户需自行安装，并遵守各项目许可证。项目源码采用 GPL-3.0-or-later，主要是为了与 BlenderProc 生态保持保守兼容；这不改变第三方项目各自的版权归属。
