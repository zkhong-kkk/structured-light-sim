# 第三方项目与方法参考

本项目自行实现仿真场景组织、条纹序列、相位解码、三角测量、融合和评价逻辑，同时使用或参考以下开源项目与公开方法：

- [BlenderProc](https://github.com/DLR-RM/BlenderProc)：Blender/Cycles 程序化仿真框架；
- [Blender](https://www.blender.org/)：Cycles 渲染器和三维场景；
- [Open3D](https://github.com/isl-org/Open3D)：点云处理、TSDF 和 Poisson 接口；
- [OpenCV](https://github.com/opencv/opencv)：图像处理和形态学操作；
- [Trimesh](https://github.com/mikedh/trimesh)：网格检查、截面和体积计算；
- [SciPy](https://github.com/scipy/scipy)：距离变换和数值工具；
- Kazhdan 与 Hoppe，*Screened Poisson Surface Reconstruction*：Poisson 拓扑分支的方法来源。

第三方项目均未作为源码复制进本仓库。引用这些项目不意味着其作者为本项目实验结果背书。
